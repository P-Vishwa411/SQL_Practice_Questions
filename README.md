# SQL_Practice_Questions

This repository contains a small, well-structured SQL practice database designed for beginners and interview preparation.
It includes related tables with sample data, SQL queries, and PostgreSQL-specific exercises.

📌 What's Included

A set of 6 related tables

Sample data for each table

SQL practice queries (JOIN, GROUP BY, subqueries, window functions)

PostgreSQL-specific queries (ILIKE, DISTINCT ON, UPSERT, JSON, arrays)

📘 SQL Practice Queries

Here are some suggested queries to practice:

Basic Queries

Get all employees and their department names

Count employees in each department

Find employees earning above the average salary

Show top 5 salaries

JOIN Queries

List all orders with customer names

Show each order with product details

Total amount spent by each customer

Aggregations

Total salary per department

Total revenue per product

Customers with more than 1 order

Subqueries

Find the second-highest salary

List employees with salary above dept average

🐘 PostgreSQL-Specific Practice

Case-insensitive search using ILIKE

DISTINCT ON to pick the latest record per group

UPSERT using ON CONFLICT

JSON/JSONB access

Arrays and unnest()

Window functions (RANK, ROW_NUMBER)
